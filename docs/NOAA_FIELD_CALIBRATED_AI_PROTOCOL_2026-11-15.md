# ROOTSHADOW field-grounded AI experiment — pre-registered evaluation

This stage trains an actual supervised machine-learning model against independently measured NOAA soil-moisture profiles. It is separate from the GPT-6 Astra language-model interpretation assistant, and **not a future drought forecasting service**.

## Target

Given today's and past NASA POWER/MERRA-2 surface/root wetness, precipitation and temperature at a model point, estimate whether a nearby NOAA USCRN depth-weighted 0–100 cm probe profile is in the bottom 40% of that station's seasonal reference distribution on the same day.

This is model-to-field **nowcast calibration research**, not irrigation advice or prediction of next week's crop stress.

## Independent observations and splits

Station inputs: Goodwell 2 E, Goodwell 2 SE, Stillwater 2 W, Stillwater 5 WNW. Each uses NOAA recorded 5/10/20/50/100 cm volumetric moisture data. A record must have all five depths to be eligible.

The seasonal reference is 2013–2019 only, computed separately for NOAA probes and NASA modeled series. It intentionally differs from the published ROOTSHADOW 1991–2020 historical reference.

- **Training:** 2013–2019.
- **Model selection validation:** 2020–2021.
- **Final untouched test:** 2022–2025.
- **Additional spatial transfer:** fit on Goodwell training data and score Stillwater test, then reverse.

Only same-day and previous NASA data are allowed as features. There are no NOAA probe values in the inference features.

## Preselected models and comparators

Three models, selected by lowest validation Brier score:
1. Logistic regression using *only* NASA modeled root-zone seasonal rank.
2. Logistic regression using NASA root and surface rank, recent changes, historical rainfall/temperature and season.
3. Scikit-learn histogram gradient-boosted classifier using those same features.

Compare the selected model with the single-feature logistic comparator on the untouched test. Also report the uncorrected NASA root-rank <40 screening confusion matrix.

Report Brier score, ROC-AUC, average precision, expected calibration error, precision, recall, specificity, false positives and misses, both pooled and for each available probe station. Report transfer without target-location training.

## Limits and stop conditions

Do not infer that performance at four Oklahoma probe stations translates to Qatar, the other 95 atlas points, farm-level precision, future rainfall, or irrigation volumes.

Even a positive relative Brier score improvement is **not** broad external validation, and temporally adjacent daily observations are not independent samples. Nearby station pairs share model inputs. Negative comparisons and transfer failures must appear in the report.

The trained scikit-learn model file is an Actions artifact, not an operational model served by the website. No live predictions are generated by this workflow. The web product may display the evaluated historical results and a clear scientific-status label only.

Run locally with \`pip install -r requirements.txt scikit-learn joblib\`, then \`python -m pytest tests/test_noaa_calibration.py -q\` and \`python -m scripts.train_noaa_calibration\`.
