# ROOTSHADOW hybrid frontend — development checkpoint

**Status:** Source implementation created, awaiting full dependency install, automated build and browser verification. Not a deployed production application.

## Direction

Hybrid user journey: approachable environmental story and location selection; advanced scientific workbench behind a toggle. Color/design: blend of Dark Earth Intelligence and Aerospace Precision. Avoid generic AI-style glossy cards or decorative data representations.

## Implemented in source

- Landing page and conceptual, explicitly labeled surface/root-zone illustration.
- MapLibre world globe/map and four selectable NASA research locations, with selection preserved across views.
- Research workspace calls the existing verified snapshot API without changing scientific code.
- Apache ECharts time series with monthly NASA percentiles, real event markers and time zoom; annual mismatch chart and nine-setting sensitivity heatmap.
- Chronological drought-event inspector, signed-lag explanations and censored-event distinctions.
- Separate simple versus scientific views, including four-site comparison, detailed Evidence Auditor, provenance and JSON evidence export.
- API schema verification using Zod; failure states do not silently substitute synthetic data.
- Mobile responsive navigation, keyboard-visible focus styles and reduced-motion handling.
